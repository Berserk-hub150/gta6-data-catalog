# GTA VI Data Catalog

A source-linked collection of six GTA VI regions with validation, search and CSV export.

## Quick start

```sh
python catalog.py --search vice
python catalog.py --csv
```

## Using your own material

Add sourced rows to data/regions.json. IDs must be unique. This collection uses public references and does not extract game files.
